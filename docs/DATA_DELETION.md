# تعليمات حذف البيانات (نموذج أولي - Data Deletion Instructions)

> نموذج أولي مطلوب لطلب Meta App Review. خصّصه ببيانات نشاطك التجاري قبل النشر.

## للعملاء
إذا كنت عميلًا محتملًا وتريد حذف بياناتك من نظامنا:
1. راسلنا على [بريد إلكتروني للتواصل] برقم هاتفك أو بريدك الإلكتروني المستخدم عند تعبئة النموذج.
2. سنحذف سجلك خلال 7 أيام عمل ونرسل لك تأكيدًا.

## آلية الحذف عبر Meta (Data Deletion Callback)
هذا النظام ينفّذ **Data Deletion Request Callback** الرسمي من Meta:
`POST /api/meta/data-deletion`

عند استلام طلب حذف موقّع من Meta (`signed_request`)، يتحقق النظام من التوقيع (HMAC-SHA256 عبر
App Secret)، ويسجّل الطلب للمراجعة اليدوية (لأن Lead Ads لا يوفر ربطًا مباشرًا بين معرّف مستخدم
فيسبوك ومعرّف العميل المحتمل لدينا)، ويعيد فورًا:
```json
{ "url": "https://.../data-deletion-status?code=...", "confirmation_code": "..." }
```
كما هو مطلوب من [توثيق Meta الرسمي](https://developers.facebook.com/docs/development/create-an-app/data-deletion-callback).

## الحذف اليدوي من لوحة التحكم
يمكن لمسؤول النظام حذف أي عميل بشكل كامل (بما في ذلك سجل تغييرات الحالة) من صفحة "العملاء"
في لوحة التحكم، أو عبر:
```
DELETE /api/leads/:id
```
